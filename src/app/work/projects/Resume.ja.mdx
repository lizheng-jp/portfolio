## 📂 プロジェクト

### [開発者生産性評価システム](/work/7-DeveloperEvalutionSystem/ja) _(Spring Boot + Next.js + GitLab API + Gemini API + Docker + Jenkins)_
- GitLab の Issue、Merge Request、Commit、レビュー、満足度アンケート、SPACE 指標を用いて、開発者生産性を可視化する社内 PoC システムを 0 から構築。
- GitLab API 連携、指標算出、AI 支援型 Merge Request 分析、データ永続化、REST API 提供を行うバックエンドサービスを実装。
- Gemini API を統合し、構造化 JSON 出力、High/Middle/Low の bounded scoring、fallback、人による確認を前提としたガードレールを設計。
- Next.js ダッシュボードで、プロジェクト単位・メンバー単位の生産性指標、AI フィードバック、改善提案を表示。
- Docker Compose ベースの実行環境、Jenkins デプロイフロー、Spring Boot Actuator、Prometheus、Grafana、Micrometer、PerformanceTimingLog による監視構成を整理。

### [会議室管理システム](/work/5-MeetingRoomsManagmentSystem) _(Spring Boot + PostgreSQL + JavaScript + Grafana)_
- 会議室の利用状況を監視・概観するための Web ベースのダッシュボードを開発。
- Grafana をバックエンド API に接続し、分析用のデータ可視化を実装。
- DataTables.js を使用して、フロントエンドに対話型データヒートマップを開発。
- クエリ速度の向上とメモリ使用量の削減のために計算方法とアルゴリズムをリファクタリングし、50 万件以上のレコードに対する 7 種類の統計分析を 10 秒以内に達成。

### [QRコード勤怠システム](/work/4-Flutter-QRCode) _(Flutter + WebView + Firebase Messaging)_
- 2 万人以上の従業員が社内で使用するために開発。
- プロキシとクライアント証明書サポートを備えた WebView を使用して、セキュアな認証を統合。
- Firebase Cloud Messaging とバックグラウンド更新により、手動更新なしで QR コードを更新できる仕組みを実装。

### [ハンディ QR コードスキャナー](/work/3-Handy) _(Android + MVVM + Retrofit + OkHttp)_
- 既存の Android QR コードスキャンアプリケーションを MVVM アーキテクチャにリファクタリングし、パフォーマンスと保守性を向上。
- Retrofit と OkHttp を使用してネットワークリクエストを統合し、API 応答速度を向上。
- アプリ更新機能を実装し、手動でのデバイスごとの更新を置き換え、リリースごとの更新時間を 6 時間削減。

### [異常検知パイプライン](/work/2-STB) _(Python + PyTorch)_
- センサーデータから製造欠陥を検出するためのマルチモデル推論パイプラインを構築。
- 効率的な後処理により、91% の再現率と 99% の分類精度を達成。
- SAM による画像セグメンテーションを用いて無関係な領域を除去し、モデル精度を 5% 改善。
- PatchCore 異常検知モデルを実装し、制約のあるハードウェアでも安定した検出結果を実現。
