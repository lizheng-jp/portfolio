## 📂 プロジェクト

### [会議室管理システム](/work/MeetingRoomsManagmentSystem) _(Spring Boot + PostgreSQL + JavaScript + Grafana)_
- 会議室の使用状況を監視・概観するためのWebベースのダッシュボードを開発。
- GrafanaをバックエンドAPIに接続し、分析用のデータ可視化を実装。
- DataTables.jsを使用して、フロントエンドに対話型データヒートマップを開発。
- クエリ速度の向上とメモリ使用量の削減のために計算方法とアルゴリズムをリファクタリングし、50万件以上のレコード（過去3年間、756会議室）に対する7つの異なる統計分析を10秒以内に達成。

### [QRコード勤怠システム](/work/Flutter-QRCode) _(Flutter + WebView + サイレントプッシュ通知)_
- 2万人以上の従業員が社内で使用するために開発。
- プロキシとクライアント証明書サポートを備えたWebViewを使用して、セキュアな認証を統合。
- Firebase Cloud Messagingとバックグラウンド更新によるバックグラウンドQRコード更新を有効にし、手動更新なしでシームレスなユーザーエクスペリエンスを実現。

### [ハンディQRコードスキャナー](/work/Handy) _(Android + MVVM + Retrofit + OkHttp)_
- 既存のAndroid QRコードスキャンアプリケーションをMVVMアーキテクチャにリファクタリングし、パフォーマンスと保守性を向上。
- RetrofitとOkHttpを使用してネットワークリクエストを統合し、API応答速度を向上させ、リソース使用量を削減。
- コードを標準化し、関連ドキュメントを作成。3言語（日本語、英語、ベトナム語）のアプリ文字列をリソースファイルに統合し、一元管理を実現。
- バッチ更新を可能にするアプリ更新機能を実装し、手動でのデバイスごとの更新を置き換え、リリースごとの更新時間を6時間短縮。

### [異常検知パイプライン](/work/STB) _(Python + PyTorch)_
- センサーデータから製造欠陥を検出するためのマルチモデル推論パイプラインを構築。
- 効率的な後処理により、91%の再現率と99%の分類精度を達成。
- 画像セグメンテーションにSAMを使用して無関係な領域を除去し、モデル精度を5%向上。
- PatchCore異常検知モデルを実装して、大幅に低い計算需要で効率的なパフォーマンスを達成し、制約のあるハードウェアでも安定した検出結果を実現。
