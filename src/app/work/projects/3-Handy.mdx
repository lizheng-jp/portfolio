## Overview
In this project, I refactored the exsiting code and implemented the MVVM architecture. I also added a new feature that allows application receive updates from the server.

## Key Features
- **MVVM**:Due to the previous code, all data interaction were in the Activity, which resulted in poor readability and maintainability. I decoupled the code to achieve a clearer code structure.
- **Communication Standardization**: Given that the previous code opened a separete thread for each communication, I standardized the communication using Retrofit and Okhttp. Employing thread pools to reduce communication overhead.
- **App Update**: Previously, updates were done by connecting to a computer, which was inefficient. After adding the download update feature, updates can now be done wirelessly.

## Challenges and Learnings
- **Refactor**: Since there is no documentation, I had to understand the existing codebase and refactor it.
- **MVVM**: Although I have previously developed using MVP, I encountered some issues while trying MVVM, especially with observing LiveData.

## Outcome
The improved application has been developed on approximately 350 terminals in the factory. Each update saves dozens of hours of work, and though holding training sessions and the new architecture, even those without Android development experience can now participate in development.
