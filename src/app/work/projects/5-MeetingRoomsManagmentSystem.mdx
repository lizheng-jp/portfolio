### Main Task
The main task of this project is to develop a web-based meeting room management system that provides a visual dashboard for each location's meeting room usage statistics. 

### Technology
Frontend: JavaScript, HTML, CSS
Backend: Java Spring Boot, Docker, CI/CD
Database: PostgreSQL
Visualization: DataTables, Grafana
